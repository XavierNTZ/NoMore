# Licensing status / Statut de la licence

## English

NoMore is intended for an open-source release. **No project licence has yet been selected or included in this initial documentation package.**

This file records that status; it is not a licence and does not grant a blanket right to reuse third-party or pre-existing material.

Before a first open-source software release, the maintainer must select an appropriate licence, publish the complete licence text in a `LICENSE` file, update the README and check ownership and dependency compatibility.

Future rights must be determined from the actual licence files, not from the project's ambition or the fact that a repository is public.

## Français

NoMore a vocation à être publié en open source. **Aucune licence de projet n’a encore été choisie ou intégrée à ce premier ensemble documentaire.**

Ce fichier constate cette situation ; il ne constitue pas une licence et n’accorde pas un droit général de réutilisation de contenus tiers ou préexistants.

Avant une première publication du logiciel sous licence open source, le porteur du projet devra choisir une licence adaptée, en ajouter le texte complet dans un fichier `LICENSE`, mettre à jour la présentation et vérifier les droits ainsi que la compatibilité des dépendances.

Les droits devront être appréciés à partir des licences effectivement publiées, et non de la seule ambition du projet ou du caractère public du dépôt.
